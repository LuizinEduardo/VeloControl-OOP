# 🦸 VeloControl-OOP

## 📋 Sobre o Projeto

Este trabalho em Java, da Faculdade Unopar, do curso de Analise e Desenvolvimento de Sistemas, 
que corresponde em criar um sistema básico de gerenciamento de veículos,
utilizando herança, polimorfismo e encapsulamento, de forma pratica, 
e resolvendo problemas reais, mostrando a facilidade, agilidade, organização do código e modularidade.

Foi criado classe Veículos e suas subclasses Carro e Moto ambos com seus atributos e métodos,
e também suas hierarquias e suas implementações especificas de cada classe, 
tornando o sistema mais robusto e flexível.

## 🎯 Objetivo

Praticar:
- Conceito de Classes
- Herança
- Polimorfismo
- Encapsulamento

## 🚀 Tecnologias

Java
